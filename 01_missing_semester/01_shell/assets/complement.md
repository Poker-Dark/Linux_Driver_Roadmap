#第一章CLI与shell补充\
1.常见目录和路径\
/ 根目录 ~ 当前目录的家目录\
.. 上一级目录 .当前目录\
2.Linux文件权限\
1) u 文件所有者\
   g 所属组\
   o 其他用户\
ex.chmod u+x hello.c\
给文件所有者添加执行属性\
2)三种基本权限\
r read 4\
w write 2\
x 执行 1\
ex.可以通过755等数字修改相应位置的权限\
3.sudo\
尝试以管理员权限执行指定命令\
4.tee命令\
可以同时将命令输出到文件和终端\
ls | tee result.txt\
即在终端输出ls的内容\
同时又将内容重定向(覆盖)到.txt文件中\
要追加则添加参数-a\
ls | tee all.txt | grep ".c"输出时显示.c文件\
5.重定向执行顺序\
cat test.txt >test.txt\
shell在执行命令时先处理重定向\
重定向时会先把所需定向的文件删干净在执行后续内容\
所以在这条命令时输出为空\
6.执行脚本\
./hello.sh(前提为 chmod授予执行权限)\
bash hello.sh\
7.定义变量\
name="Linux" 注意等号两边不能有空格\
8.命令替换\
dir=$(pwd) echo "$dir" \
输出pwd的内容\
9.if语句下的数字比较\
-eq 等于 | -ne 不等于\
-gt 大于 | -ge 大于等于\
-lt 小于 | -le 小于等于\
10.if语句下的字符串比较\
= 相等 | != 不相等\
-z 字符串为空 | -n 字符串非空\
11.文件测试\
-e 路径存在 | -f 普通文件存在\
-d 目录存在 \
12.函数\
1)函数参数\
$# 代表参数数量\
2)函数返回值若存在(return exit echo)\
用echo或命令替换输出\
13.脚本参数传递\
$0 脚本名称或调用路径 \
$# 参数数量\ 
$@ 所有参数(各参数独立保存）\
$* 所有参数(所有参数合为一个整体) \
$@和$*主要区分于for循环的输出中\
for arg in "@#"\
do \
  echo "$arg"\
done\
若为$@则按参数分行输出，独立处理\
若为$*则只输出一行\
14.shell数组\
也是从0开始\
${num[0]} 数组的第零个变量\
${num[@]} 数组所有变量,用于在for中遍历输出各个变量使用\
${#num[@]} 数组长度,其输出为数组的真实个数，不存在或没有则不包含\
num+={40} 添加元素,加在数组的末尾\
num[1]=10 修改元素\
unset num[0] 删除元素 删除后下标不会自动排序,保持原来\
15.shell字符串处理\
1)获取字符串长度 echo "${#name}"\
2)字符串截取\
${name:8:5}\
从第八个字母开始,截取5个长度,注意起始位置从零开始\
3)字符串替换\
${name\Linux\stm32}\
用stm32替换Linux,这里的Linux指的是第一个匹配项\
替换所有匹配项\
${name\\Linux\stm32}\
4)删除字符串末尾内容\
filename="main.c"\
echo "${filename%.*}\
输出main\
%从末尾删掉最短匹配.*部分\
%%从末尾删掉最长匹配部分\
即name="main.c.backup"时可以输出main\
5)提取文件名\
name=/home/yami/main.c\
echo "${name##*/} \
从开头删掉匹配*/ 的最长部分\
输出main.c\
6).提取拓展名\
echo "${name##*.}\
输出c\
7)默认值处理\
${变量:-默认值}\
变量未设置或为空时 临时使用默认值\
${变量:=默认值}\
变量未设置或为空时 使用默认值并赋值给变量\
:?变量未设置或为空时报错\
:+变量已设置且非空时使用备用值\
16.shell脚本错误处理\
1.检查参数数量\
if[$# -eq 0];then\
 echo"缺少参数">&2\
 exit 1\
fi\
2.检查文件是否存在\
if[! -f "$filepath"];then
 echo"不存在">&2
 exit 1
fi
3.set -e\
某些命令执行失败或报错时自动退出\
4.set -u\
使用未定义的变量时会报错\
5.set -o \
管道中有命令执行出错时报错退出,不会继续执行\
