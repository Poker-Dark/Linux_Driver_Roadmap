 # 第一章：命令行与 Shell

> 课程：MIT Missing Semester（中文版）
> 日期：2026-11-15
> 时长：约 2 小时

## 本章概览

Shell 是操作系统的文本接口。本章覆盖：导航、程序查找、管道与重定向、
shell 脚本基础。

## 知识点及笔记概览
> man,echo，cd及pwd(查询当前工作路径)的基本使用方法
> 了解路径（相对路径，怎样列出所有路径，找出路径的方法）
> ls的基本和拓展用法及cat的使用
> shell语言的具体形式
> glob及创建目录，创建和写文件，了解各通配符的用法
> 重定向
> 退出码及返回码
> 解决cd为什么是内建命令而非独立的小程序的问题
> 怎样正确建立脚本及修改脚本文件的方式
> for和if的基本使用方法
> cp，find，sed，awd，sort，uniq，head，tr，grep的用法
> xargs，wc，curl，jq的用法
> 拆解SSH日志
